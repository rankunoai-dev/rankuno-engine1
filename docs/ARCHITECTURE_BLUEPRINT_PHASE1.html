3. Phase 1: Multi-Dimensional Page Classification Engine

Phase 1 classifies website URLs across 3 complementary interfaces to build a structured content graph:

  • Interface 1: Page Type & Hierarchy (L0 Homepage, L1 Primary Nav Hub, L2 Sub-Nav Hub, L3 Leaf Page, Utility).
  • Interface 2: Theme & Topical Cluster (Business Niche, Content Silos, Subject Matter).
  • Interface 3: Semantic Intent & Conversion Role (Informational, Commercial Investigation, Transactional, Navigational).

3.1 The 6-Signal Consensus Architecture (Fail-Safe Strategy)

To guarantee zero classification failures on complex or flat websites, the engine evaluates 6 independent signals:

1. ARIA Nav Tree Signal  --> Inspects Accessibility ARIA tags (role="navigation") & nested <ul>/<li> (Resolves Hidden/Hamburger Menus).
2. CMS API Endpoint      --> Queries WordPress (/wp-json/) & Shopify (/collections.json) endpoints (Resolves Flat URLs).
3. Grouped XML Sitemaps  --> Parses product-sitemap.xml, category-sitemap.xml, post-sitemap.xml.
4. Schema.org JSON-LD    --> Parses @graph types (CollectionPage, Product, Article, Service).
5. Link In-Degree        --> Evaluates internal link weight (>=1000 links = L1 Primary Hub).
6. LLM Zero-Shot Backup  --> Gemini 3.6 Flash fallback when structural signals are ambiguous.

3.2 Pydantic Data Contracts

from enum import Enum
from typing import List, Optional
from pydantic import BaseModel, Field

class HierarchyLevel(str, Enum):
    L0_HOMEPAGE = "L0_HOMEPAGE"
    L1_PRIMARY_NAV_HUB = "L1_PRIMARY_NAV_HUB"
    L2_SUB_NAV_HUB = "L2_SUB_NAV_HUB"
    L3_LEAF_PAGE = "L3_LEAF_PAGE"
    UTILITY_PAGE = "UTILITY_PAGE"

class PrimaryPageType(str, Enum):
    HOMEPAGE = "HOMEPAGE"
    SERVICE_CATEGORY_HUB = "SERVICE_CATEGORY_HUB"
    SERVICE_DETAIL_PAGE = "SERVICE_DETAIL_PAGE"
    PRODUCT_CATEGORY_HUB = "PRODUCT_CATEGORY_HUB"
    PRODUCT_DETAIL_PAGE = "PRODUCT_DETAIL_PAGE"
    BLOG_HUB = "BLOG_HUB"
    BLOG_ARTICLE = "BLOG_ARTICLE"
    COMPANY_ABOUT = "COMPANY_ABOUT"
    COMMERCIAL_LEAD_GEN = "COMMERCIAL_LEAD_GEN"
    FACETED_FILTER = "FACETED_FILTER"
    UTILITY_LEGAL = "UTILITY_LEGAL"
    UNKNOWN = "UNKNOWN"

class SignalScore(BaseModel):
    source: str
    suggested_level: HierarchyLevel
    suggested_page_type: PrimaryPageType
    confidence: float = Field(ge=0.0, le=1.0)
    notes: str

class FullPageIntelligenceProfile(BaseModel):
    url: str
    normalized_path: str
    hierarchy_level: HierarchyLevel
    primary_page_type: PrimaryPageType
    nav_parent_url: Optional[str]
    breadcrumb_path: List[str]
    topical_category: str
    sub_topic: Optional[str]
    search_intent: str
    conversion_role: str
    signals_evaluated: List[SignalScore]
    final_confidence_score: float = Field(ge=0.0, le=1.0)
    consensus_method: str

4. Edge-Case & Security Audit Matrix

Edge Case / Threat Vulnerability / Cause Rankuno Architectural Guardrail
Hamburger / Hidden Mobile Navs CSS hides menu (display: none). Inspect DOM ARIA tree (role="navigation") ignoring visual CSS.
Flat URLs (site.com/page) Directory path regex breaks. Query CMS Endpoints (/collections.json) & Sitemap index grouping.
JavaScript SPAs Empty <div id="root"> returned. Playwright headless browser rendering fallback.
Multi-Language Paths Locale prefixes skew paths (/en/services). Path Normalizer strips locale prefixes before hierarchy matching.
Faceted Filter Params Query params (?color=red) create infinite URLs. Parameter Normalizer flags parameterized URLs as FACETED_FILTER.
API Cost Overflow Unbounded LLM calls. Rate-limiter & caching layer: LLM invoked only when 5 structural signals are ambiguous.
